### ADR-001: 언어 · 프레임워크 · 빌드툴

**결정**: Java {버전} + Spring Boot {버전} + {Gradle Groovy DSL / Gradle Kotlin DSL / Maven}

**이유**: {왜 이 조합인지. 기존 사내 프로젝트와의 정합성, 팀 숙련도, 라이브러리 호환 등}

**트레이드오프**:
- Spring Boot 3.x: Java 17+ 필수, `javax.*` → `jakarta.*` 전환 필요
- Spring Boot 2.7.x: Java 8~17 지원, 커뮤니티 지원 종료됨 — 신규 프로젝트는 3.x 권장
- Gradle Groovy DSL: 기존 사내 스크립트와 호환. IDE 자동완성·타입 안전성은 약함
- Gradle Kotlin DSL: 타입 안전·자동완성 이점, 초기 학습비용과 스크립트 컴파일 시간 증가
- Maven: 선언적·예측 가능, 커스텀 빌드 로직 작성은 불편

> 결정 후 `CLAUDE.md`의 `## 명령어` 섹션을 이 빌드툴 기준으로 채울 것.
> 그 섹션이 모든 검증 커맨드의 단일 진실원이다.

### ADR-002: 아키텍처 패턴

**결정**: {Layered Architecture / Hexagonal (Ports & Adapters) / DDD 중 선택}

**이유**: {왜 이 패턴을 선택했는지}

**트레이드오프**:
- **Layered**: 빠른 시작·낮은 학습비용. 도메인이 커지면 레이어 간 의존 방향 관리 필요.
- **Hexagonal**: 프레임워크 비의존 도메인 → 테스트 용이. 초기 보일러플레이트 증가.
- **DDD**: 복잡한 도메인 경계를 Bounded Context로 명확히 분리. 설계 선행 비용 큼.

> 기존 코드가 있는 프로젝트라면 **새 패턴을 도입하기 전에 현재 구조를 먼저 확인하라.**
> 실제 구조가 위 셋 중 어디에도 딱 맞지 않으면, 억지로 분류하지 말고
> `ARCHITECTURE.md`에 실제 구조를 그대로 기술한 뒤 그것을 기준으로 삼는다.
>
> 결정 후 `ARCHITECTURE.md`의 디렉토리 구조 / 패턴 / 데이터 흐름 섹션을 채울 것.

### ADR-003: 영속성 · 마이그레이션

**결정**: {Spring Data JPA + Hibernate / MyBatis / jOOQ} + {Flyway / Liquibase / DBA 관리 DDL}

**이유**: {왜 이 조합인지}

**트레이드오프**:
- **JPA**: 객체-관계 매핑 자동화. 복잡 쿼리는 JPQL/QueryDSL 필요, 발생 SQL 추적이 어려움
- **MyBatis**: SQL 직접 제어·동적 쿼리 유연. XML 매퍼와 Java 인터페이스 이중 관리
- **jOOQ**: 타입 안전 SQL DSL, 스키마 변경을 컴파일 타임에 감지. 코드 생성 파이프라인 필요
- **Flyway**: SQL 파일 기반, 단순하고 직관적
- **Liquibase**: XML/YAML/JSON 지원, 롤백 내장
- **DBA 관리 DDL**: 애플리케이션 저장소에 스키마 이력이 남지 않음 — 변경 시 수동 동기화 필요

### ADR-004: 테스트 스택

**결정**: JUnit 5 + {AssertJ} + {Mockito} {+ Testcontainers 여부}

**이유**: {왜 이 스택인지}

**트레이드오프**:
- **Testcontainers 사용**: 실제 DB/외부 서비스 기반 통합 테스트 → 정확도 높음, CI 시간 증가, Docker 필요
- **인메모리 DB(H2 등)**: 빠른 실행. DB 방언 차이로 프로덕션에서만 터지는 버그 가능
- **전체 `@SpringBootTest` 비중이 높을수록** 하네스의 step별 AC 실행 시간이 길어진다. 단위 테스트를 기본으로 두라.

### ADR-005: 사내/공용 프레임워크 사용 여부

**결정**: {사용 — `docs/STACK_PROFILE.md` 참조 / 미사용}

**이유**: {왜 도입했는지 또는 왜 쓰지 않는지}

**트레이드오프**:
- **사용**: 공통 설정·응답 포맷·보안이 표준화됨. 대신 사내 아티팩트 저장소 접근(사내망/VPN)이 빌드 전제 조건이 되고, 프레임워크 버전에 종속됨
- **미사용**: 빌드가 외부 의존 없이 완결됨. 공통 관심사를 직접 구현해야 함
